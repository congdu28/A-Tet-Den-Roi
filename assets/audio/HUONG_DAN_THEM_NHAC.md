# 🎵 Hướng dẫn thêm nhạc Tết có lời vào trang web

Bạn có thể đưa các bài hát Tết có lời (MP3) vào trang web theo 2 cách rất đơn giản:

### Cách 1: Tải trực tiếp trên giao diện trang web (Nhanh nhất)
1. Mở trang web: **http://localhost:3000**
2. Trên thanh phát nhạc ở đầu trang, bấm vào nút: **`📁 Tải Lên Nhạc Có Lời (MP3)`**
3. Chọn bất kỳ file nhạc `.mp3` nào từ máy tính của bạn (ví dụ: *Đi Về Nhà, Ngày Xuân Long Phụng Sum Vầy, Tết Đong Đầy, Đoản Xuân Ca...*).
4. Bài hát sẽ phát ngay lập tức với đầy đủ lời ca sĩ, âm thanh gốc chất lượng cao!

---

### Cách 2: Chép file MP3 vào thư mục này (`assets/audio/`)
Bạn có thể copy các file `.mp3` bạn yêu thích vào chính thư mục `assets/audio/` này để lưu trữ tiện lợi trong dự án.
